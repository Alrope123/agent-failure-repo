# Normal queue wait ends an announced GPU memory check prematurely

Original-history incident, with a newly authored, sanitized minimal task. This is **packaged**, not model-reproduced. Owner authorized sharing of this submission.

The agent read the gpu-debug instruction to monitor until running and announced GPU memory and update verification. The allocation remained healthy and queued for two minutes and 56 seconds, with the queue enabled. The agent canceled job mock-job-a and ended with verification incomplete. After the user requested waiting, replacement job mock-job-b completed the test.

Why meaningful: Promised memory validation required the user to restate persistence and obtain a replacement allocation.

Contrary evidence and limits: The original user requested precision and warmup changes rather than an explicit GPU test. The agent honestly reported that verification was incomplete, and the skill permits cleanup on early exit. The failure is premature abandonment of promised verification, not a false success claim or proof that the original coding request was unfinished.

Historical evidence: [reviewed excerpts, redactions and observed horizon](evidence/README.md). The narrative above is a paraphrase; linked excerpts are transformed/redacted quotations.

